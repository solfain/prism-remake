# SOL Launcher Program Info

This is SOL Launcher's program info which contains information about:

- Application name and logo (and branding in general)
- Various URLs and API endpoints
- Desktop file

SOL Launcher is an independent project based on Prism Launcher. The logo and icons in this folder are SOL's own
(an iceberg mark, see `docs/sol/DESIGN.md`); they are not Prism Launcher artwork.
